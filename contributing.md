## 🔧 Troubleshooting

| **Issue** | **Possible Cause** | **Solution** |
|-----------|--------------------|----------|
| **Slow Response** | Insufficient VRAM or CPU overhead | Use a smaller quantized model |
| **Looping Text** | Temperature set too high/low | Adjust temperature to 0.8 - 1.2 |
| **Context Loss** | Exceeded context window | Clear chat history or use a longer model |
